The box below is a chat with a real language model. When you press Load model, your browser downloads quantised weights once and runs every token on your own machine: on the graphics card through WebGPU when the browser allows it, on the CPU through WebAssembly when it doesn't. There is no API behind it. This is a placeholder post, but the demo is real.

What happens when you press Load

  1. The page starts a module worker so the model never blocks scrolling or typing.
  2. It asks the browser for a WebGPU adapter. If there is one, the worker fetches 4-bit weights (q4f16 when the GPU has 16-bit float shaders, q4 when it doesn’t).
  3. If WebGPU is missing, or the browser’s limits are too tight for the kernels,1 the worker switches to WebAssembly with 8-bit weights.
  4. Each new token is one forward pass, with the KV cache kept between steps. The weights stay in the browser’s Cache Storage, so the next visit starts at once.

The memory needed is roughly the parameter count times the bits per weight:

bytes≈Nparams⋅b8+2⋅L⋅nctx⋅d⋅2⏟KV cache, fp16\text{bytes} \approx N_\text{params} \cdot \frac{b}{8} + \underbrace{2 \cdot L \cdot n_\text{ctx} \cdot d \cdot 2}_{\text{KV cache, fp16}} bytes≈Nparams​⋅8b​+KV cache, fp162⋅L⋅nctx​⋅d⋅2​​

For a 135M-parameter model at b=8b = 8b=8 that is about 135 MB of weights before overhead, small enough for a phone.

The worker, in brief

The fallback is a second attempt with device: 'wasm' when the first one throws. A one-token warm-up right after loading makes any WebGPU error show up during loading, not in the middle of your first question.

Small models are often confidently wrong. That is part of the point: it is easier to build intuition for sampling, context length and quantisation when you can watch a model fail up close, on your own machine.2

Notes

  1. Firefox, for example, allows fewer storage buffers per shader stage than some compiled kernels ask for. That is a limit of the browser’s WebGPU, not of the model’s size. ↩︎

  2. Because the model runs locally, nothing you type leaves your browser. The only network traffic is the one-time weight download and the ONNX Runtime files. ↩︎
