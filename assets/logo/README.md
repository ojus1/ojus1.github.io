# Logo

Sun arc over joined hands. Generated by `node scripts/logo.mjs` (edit the geometry there, then rerun).

- `logo.svg` / `logo-dark.svg`: tight crop, for light / dark backgrounds. `logo-adaptive.svg` follows the OS colour scheme.
- `logo-square*.svg`: square crop with padding, for avatars and icons. `logo-paper.svg` / `logo-night.svg` include a background.
- PNGs: `logo-{64..2048}w.png` and `logo-dark-*w.png` (transparent, by width); `logo-square-*`, `logo-square-dark-*`, `logo-paper-*`, `logo-night-*` at 16 to 1024 px.
- Site icons live one level up: `favicon.svg`, `favicon.ico` (16/32/48), `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`.

Colours: sun `#e08a2b` (`#f0993a` on dark), hands `#262320` (`#f1eee8` on dark).
